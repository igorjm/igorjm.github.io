# Tech Recruiting Lens — Senior Full-Stack Engineer

Dual perspective: **HR screener (6-second scan + ATS)** and **engineering hiring manager (depth + ownership)**.

## What recruiters scan in 6 seconds

1. Current title and company
2. Years of experience (8+ ✓)
3. Stack match to JD
4. One standout metric or brand-name domain
5. Location / remote fit

## Red flags to avoid in materials

- Title inflation without scope to match
- Frontend-only framing when applying to full-stack roles (or vice versa)
- Tool laundry lists without outcomes
- Gaps in employment unexplained
- Inconsistent dates between CV, LinkedIn, and portfolio
- Side projects listed but broken links or empty repos

Reviewers will check:

1. **Pinned repos** — AI SaaS, Next.js apps, portfolio itself
2. **README quality** — setup, purpose, stack
3. **Commit history** — active vs stale
4. **Live demos** — Vercel links from portfolio

Recommend keeping 3–5 best repos polished; align READMEs with career narrative.

## Role-fit scoring (for career-advisor agent)

When user asks "should I apply?":

| Criterion | Weight |
|-----------|--------|
| Stack overlap | High |
| Seniority match | High |
| Domain adjacency | Medium |
| Remote/geo fit | High |
| Leadership scope match | Medium |
| Compensation alignment | User-defined |

Score 4/5+ → apply with tailored CV. Score 3 → apply if growth goal aligns. Below 3 → pass or network first.

## Questions agents should ask before strong recommendations
