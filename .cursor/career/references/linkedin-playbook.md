# LinkedIn Playbook — Senior Software Engineer

Reference for profile optimization and content. Apply with `voice.md` and `profile.md`.

## Profile audit checklist

- [ ] **Headline** — Role + specialty + value (120 chars max); not just employer title
- [ ] **Banner** — Clean, optional tagline or domain keywords
- [ ] **About** — Hook → proof → domains → CTA (see structure below)
- [ ] **Featured** — Portfolio, best 2–3 projects, resume PDF
- [ ] **Experience** — Bullets match CV; metrics where possible
- [ ] **Skills** — Top 3 pinned align with target role (Java, React, TypeScript, etc.)
- [ ] **Recommendations** — 2–3 from peers/managers if available
- [ ] **Activity** — Consistent posting or commenting (quality > quantity)

## Headline formula

```
[Seniority] [Role] | [Stack or domain] | [Value prop or domain]
```

**Examples (EN):**
- Senior Software Engineer | Full-Stack (Java, React, TS) | Analytics & Product Engineering
- Senior Full-Stack Engineer · Java · React · Building scalable product in complex domains

**Examples (PT-BR):**
- Engenheiro de Software Sênior | Full-Stack (Java, React, TS) | Engenharia de Produto
- Desenvolvedor Full-Stack Sênior · Java · React · Produtos escaláveis em domínios complexos

## About section structure

1. **Hook (1–2 lines)** — Who you are + years + specialty
2. **Proof (2–3 lines)** — Metrics and flagship outcomes (25% perf, hackathon → product, 50% report time)
3. **Domains (2–3 lines)** — Cognyte analytics, healthcare, EdTech
4. **Stack (1 line)** — Java, Spring Boot, React, TypeScript, PostgreSQL + modern side projects
5. **CTA (1 line)** — Open to conversations / links to portfolio and email

Keep under ~2,600 characters. Use short paragraphs and line breaks for mobile readability.

## Post templates

### Technical insight

```
[Hook — outcome or contrarian take in line 1]

[2–4 short paragraphs: context, what you did, what you learned]

[Optional: one concrete detail — metric, pattern, or trade-off]

[CTA — question or link]
```

### Project launch

```
Shipped [project]: [one-line value prop].

Built with [stack]. [One metric or user outcome if any].

[Link]

What would you improve in v2?
```

### Career milestone

```
[Year/role transition or achievement — specific, not vague]

[What you learned or what you're looking forward to]

Grateful to [team/context if appropriate].
```

## Posting cadence

- **Minimum viable:** 1 post every 2–4 weeks
- **Growth mode:** 1 post per week
- **Senior engineer norm:** Fewer posts, higher signal — no daily fluff

## Hashtags

- Use 0–3 relevant tags max for senior technical audience
- Prefer: `#softwareengineering` `#fullstack` `#react` `#java` — only if natural
- Avoid hashtag stuffing

## EN vs PT-BR market

| Aspect | EN (global) | PT-BR (Brazil) |
|--------|-------------|----------------|
| Tone | Direct, impact-first | Slightly more formal in About |
| Headline | Standard international titles | "Engenheiro de Software Sênior" common |
| CTA | "Let's connect" / portfolio link | "Vamos conversar" / link portfólio |
| Employers | Remote global, product cos | Nubank-style, fintechs, consultancies, US remote from BR |

## Consistency checks

Before publishing any LinkedIn update:

1. Titles and dates match `profile.md`
2. Metrics match `achievements.md`
3. Tone matches `voice.md`
4. Compare with `linkedin-baseline.md` if doing incremental updates
