# Brand Voice — Igor Melo

Use this file for tone and framing across LinkedIn, CV, cover letters, and posts.

## Core positioning

- **Tagline:** Building software with intentionality and craft.
- **Level:** Senior full-stack engineer, 8+ years, IC with leadership signals (mentoring, squad leadership, hackathon → product).
- **Stack identity:** Java/Spring Boot + React/TypeScript + PostgreSQL — with modern side projects (Next.js, AI, Stripe, Supabase, React Native).

## Domains (proof of complexity)

- Global intelligence / investigative analytics (Cognyte)
- EdTech platforms and theme systems (Konviva)
- Healthcare / radiology imaging and reporting (Animati)

## Tone

- Confident but not arrogant — lead with outcomes and scope, not adjectives.
- Precise and concrete — metrics, technologies, and user impact when available.
- Product-minded — connect engineering work to user and business value.
- Bilingual-aware — same facts in EN and PT-BR; adapt formality, not achievements.

## Do

- Use action verbs: designed, built, reduced, delivered, led, mentored, shipped.
- Quantify when possible: 25% processing reduction, 50% report creation time cut, 8+ years.
- Name domains and scale: global platform, healthcare clients, security/operations teams.
- Highlight end-to-end ownership: frontend + backend + data/reporting.
- Reference side projects as proof of modern stack and product building.

## Avoid

- "Passionate developer", "rockstar", "ninja", "guru".
- Buzzword soup without proof (synergy, leverage, disrupt).
- Junior framing ("eager to learn", "looking for my first opportunity") — inconsistent with senior profile.
- Listing every tool — group by category; prioritize what matches the target role.
- Inventing metrics, titles, or certifications — check `gaps.md` and ask if missing.
